xpufx Package Repository

Public mirror for pre-built binaries from private builders.

Provides Arch pacman and Debian apt repos plus standalone releases.

Arch (CachyOS / Arch)

[xpufx]
Server = https://xpufx.github.io/xpufx-pkgs/arch/$arch
SigLevel = Optional TrustAll

Then sudo pacman -Sy and pacman -S paseo-cli-git paseo-desktop-git tone3000-plugin tone3000-plugin-bin

Debian / Ubuntu (future)

apt deb https://xpufx.github.io/xpufx-pkgs/apt stable main

Source: github.com/xpufx/xpufx-pkgs — built by private builder
